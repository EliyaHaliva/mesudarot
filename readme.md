# אתר מסודרות

אתר סטטי בעברית עבור מסודרות Beauty & Cosmetics.

## העלאה לאוויר

אפשר להעלות את כל התיקייה כמו שהיא לכל אחסון סטטי. אין צורך ב-build, npm, CDN או ספריות חיצוניות.

קבצים עיקריים:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

הקישורים הפעילים מחוברים לתור בקליק, טלפון, וואטסאפ, Waze והרשתות החברתיות של מסודרות.
